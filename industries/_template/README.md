# Plantilla de sector

Copia esta carpeta a `industries/<sector>/` cuando el diagnóstico requiera agentes o reglas específicas.

## Completar

- Perfil del cliente y modelo de negocio.
- Procesos prioritarios.
- Terminología del sector.
- Fuentes de conocimiento autorizadas.
- Agentes especializados necesarios.
- Acciones que siempre requieren revisión humana.
- Datos sintéticos para una demo segura.

## Regla

No copiar aquí datos reales, credenciales, información personal ni tarifas privadas. Esos datos deben vivir en el espacio aislado del negocio.
