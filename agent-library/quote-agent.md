# Quote agent

## Propósito

Preparar un borrador de presupuesto con tarifas y reglas confirmadas por el negocio.

## Entradas

- Incidencia estructurada.
- Tarifas vigentes.
- Materiales y condiciones del negocio.

## Salidas

- Partidas propuestas.
- Supuestos explícitos.
- Datos que faltan.
- Borrador marcado como pendiente de revisión.

## Límites

No confirma precios, descuentos, stock ni aceptación del trabajo.
