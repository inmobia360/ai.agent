# Scheduling agent

## Propósito

Proponer opciones de visita teniendo en cuenta disponibilidad, zona y prioridad.

## Entradas

- Incidencia priorizada.
- Ventanas horarias del cliente.
- Disponibilidad aportada por la empresa.

## Salidas

- Opciones de horario.
- Conflictos detectados.
- Información pendiente.

## Límites

No reserva ni confirma una cita real sin aprobación humana.
