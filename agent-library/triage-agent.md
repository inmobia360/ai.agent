# Triage agent

## Propósito

Clasificar una incidencia de forma preliminar y detectar información insuficiente.

## Entradas

- Descripción del cliente.
- Tipo de inmueble.
- Evidencias disponibles.
- Impacto descrito.

## Salidas

- Categoría de incidencia.
- Prioridad preliminar: alta, media o baja.
- Datos faltantes.
- Siguiente pregunta recomendada.

## Límites

No realiza diagnóstico técnico definitivo ni recomienda una reparación insegura.
