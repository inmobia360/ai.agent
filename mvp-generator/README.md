# Generador MVP

La demo estática de `index.html` representa el flujo de una propuesta aprobable. El panel permanece bloqueado hasta pulsar la aprobación; en producción, esa decisión debe persistirse en `scope-approved.yaml` y asociarse a un cliente y una versión.

Abrir `index.html` directamente en un navegador para revisar la demo. No requiere dependencias ni conexión externa.
